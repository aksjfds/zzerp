# 外购入库工艺

外购配件继续使用 BOM 配件节点，并把仓库部门的“外购入库”配置为该配件的首道工艺。

推荐流程：

```text
外购配件 -> 外购入库 -> QC（可选）-> 装配或后续工艺
```

“外购入库”在数据库中使用 `procedure_type = purchase_receipt` 标识。业务判断不得依赖可修改的工序名称。
创建外购入库单时会把该类型复制到工单快照，之后修改工序配置不会改变历史工单的分批到货规则。

订单确认后，外购配件需求进入仓库部门。仓库创建外购入库单，并可按实际到货数量分批登记。每批到货立即流转到下一节点；连接 QC 时生成待检批次，否则直接进入装配或后续工艺。全部数量到货后外购入库单关闭。

当前版本只管理需求数量和到货流转，不包含供应商、价格、采购审批、付款和退货。需要这些能力时应新增独立采购单领域，外购入库工艺继续作为采购到货与生产流程之间的边界。
