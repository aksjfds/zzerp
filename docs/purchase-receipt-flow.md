# 外购入库工艺

外购配件继续使用 BOM 配件节点，并把仓库部门的“外购入库”配置为首道宏观工艺：

```text
外购配件 -> 外购入库 -> 装配或后续工艺
```

“外购入库”使用 `procedure_type = purchase_receipt` 和 `work_order_type = purchase_receipt`。它不使用生产标记，也不依赖可修改的工艺名称判断业务类型。

订单确认后，外购需求进入仓库部门。仓库创建外购入库工单，可按实际到货数量分批登记，并在每次登记时选择直接入库或送 QC。直接完成沿宏观流程进入下一节点；QC 合格进入相同目标，返工回到本次工单的来源库存，报废和遗失离开生产。

QC 不作为 `flow_json` 节点，也不配置合格品去向。当前版本不包含供应商、价格、采购审批、付款和退货。
