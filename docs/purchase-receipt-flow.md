# 外购入库工艺

外购配件继续使用 BOM 配件节点，并把仓库部门的“外购入库”配置为首道宏观工艺：

```text
外购配件 -> 外购入库 -> [QC] -> 装配、后续工艺或发货
```

“外购入库”使用 `procedure_type = purchase_receipt` 和 `work_order_type = purchase_receipt`。它不使用生产标记，也不依赖可修改的工艺名称判断业务类型。

订单确认后，外购需求进入仓库部门。仓库创建外购入库工单，可按实际到货数量分批登记。外购到下一节点若发生跨部门流转，流程中必须配置独立 QC；同部门流转可以直接进行。QC 合格数量停留在 QC 节点，由 QC 分批放行到其后续节点；返工回到本次工单的来源库存，报废和遗失离开生产。

QC 是 `flow_json` 中的独立节点，合格品去向就是该 QC 节点唯一的普通后续节点。若后续为“发货”，放行后产品离开生产系统且不再形成库存。当前版本不包含供应商、价格、采购审批、付款和退货。
