# 生产页面标记交互

生产页面左侧只显示“配件 + 宏观工艺”的父卡片，不按标记组合重复配件。标准工艺父卡片只提供“出货”，开工单按钮位于横栏的标记组合卡片；外购没有标记组合栏，仍由父卡片提供“开工单”。

右侧上方是横向标记组合栏，与下方工单栏同级。每张卡片只显示：

- 标记组合名称；
- 加工中；
- 质检中；
- 已完成。

组合以集合区分，不配置顺序。未打标记是一张独立卡片；`粗1`、`粗1 + 粗2` 等非空集合分别是一张卡片。选择非空组合后，下方只显示目标为该组合的工单。

点击标记组合卡片中的“开工单”后，该卡片直接作为工单来源；弹窗通过 `ElInputTag` 输入一个或多个本次新增标记，再填写数量和工人。输入框根据当前文字筛选并展示该工艺 `procedure_tag` 表中的已有标记建议，已经输入或来源组合已有的标记不会再次建议；也允许直接输入新名称。弹窗展示合并后的目标组合预览。多个标记只创建一张工单；重复输入会合并，来源组合已有的标记不能再次添加，一张工单最多新增 20 个标记。

工单卡片按钮为“完成、送检、取消工单”。每个 QC 批次显示“等待 QC、全部合格、含返工、含报废/遗失或混合异常”结果标签。“完成”由生产部门主动结单，存在待检或待返工数量时不可使用；“送检”只提交尚未首次送检的加工数量。QC 录入返工后，对应批次显示“返工送检”，点击后仍在原工单下创建复检批次。出货弹窗只列出有可用已完成数量的非空组合。
