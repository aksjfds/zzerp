# 生产页面标记交互

生产页面左侧只显示“配件 + 宏观工艺”的父卡片，不按标记组合重复配件。标准工艺父卡片提供“出货”和“开工单”；外购没有标记组合筛选栏，也由父卡片开工单。

`repository-filter-bar` 右侧提供两个多选标签输入框，分别筛选已有标记和正在新增的标记。下方工单栏根据这两个条件筛选工单；标记组合本身不再作为可点击的开单卡片。

工单及库存统计仍按标记组合展示：

- 标记组合名称；
- 加工中；
- 质检中；
- 已完成。

组合以集合区分，不配置顺序。未打标记是一张独立卡片；`粗1`、`粗1 + 粗2` 等非空集合分别是一张卡片。选择非空组合后，下方只显示目标为该组合的工单。

点击 repository 卡片的“开工单”后，弹窗通过 `ElSelect multiple` 输入或选择一个或多个本次新增标记，再填写数量和工人。建议项只来自当前 BOM 配件在该工艺下已配置的标记，同时允许直接输入新名称。新名称开单成功后自动写入该配件的标记配置，单价暂为空。弹窗展示合并后的目标组合预览。多个标记只创建一张工单；重复输入会合并，来源组合已有的标记不能再次添加，一张工单最多新增 20 个标记。

生产部门工作台页头提供“标记与单价配置”入口。配置页按当前产品版本的 BOM 配件分组，只列出该配件在流程图装配节点之前经过的本部门标准工艺；每个工艺可多选或新建标记，并分别维护非负计件单价。只有 `production:manage` 权限可以保存，只有查看权限时页面为只读。

流程图工艺节点通过 `qc_required` 配置是否需要 QC。需要 QC 时工单显示“送检”，所有数量完成检验且没有待返工数量后，生产部门才能点击“完成”结单；无需 QC 时不显示“送检”，剩余数量由“完成”直接处理。每个 QC 批次显示“等待 QC、全部合格、含返工、含报废/遗失或混合异常”结果标签。QC 录入返工后，对应批次显示“返工送检”，点击后仍在原工单下创建复检批次。出货弹窗只列出有可用已完成数量的非空组合。
