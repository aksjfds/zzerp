# 生产页面标记交互

生产页面左侧只显示“配件 + 宏观工艺”的父卡片，不按标记组合重复配件。标准工艺父卡片只负责开工单，不允许绕过 QC 出货；外购没有标记组合筛选栏，也由父卡片开工单。

`repository-filter-bar` 右侧提供两个多选标签输入框，分别筛选已有标记和正在新增的标记。下方工单栏根据这两个条件筛选工单；标记组合本身不再作为可点击的开单卡片。

工单及库存统计仍按标记组合展示：

- 标记组合名称；
- 加工中；
- 质检中；
- 已完成。

组合以集合区分，不配置顺序。未打标记是一张独立卡片；`粗1`、`粗1 + 粗2` 等非空集合分别是一张卡片。选择非空组合后，下方只显示目标为该组合的工单。

点击 repository 卡片的“开工单”后，弹窗通过 `ElSelect multiple` 选择一个或多个本次新增标记，再填写数量和工人。选项只来自当前 BOM 配件在该工艺下预先配置的必做标记，不允许在开单时新建。弹窗展示合并后的目标组合预览。多个标记只创建一张工单；重复输入会合并，来源组合已有的标记不能再次添加，一张工单最多新增 20 个标记。未配置必做标记时不能开单。

生产部门工作台页头提供“标记与单价配置”入口。配置页按当前产品版本的 BOM 配件分组，只列出该配件在流程图装配节点之前经过的本部门标准工艺；每个工艺可多选或新建必做标记，并分别维护非负计件单价。该配件与工艺一旦开过工单，必做标记集合冻结，仍可修改单价。只有 `production:manage` 权限可以保存，只有查看权限时页面为只读。

标准工艺工单只显示“送检”。非最终标记合格后成为可继续加工的目标组合；最终标记合格后显示在 QC 页面，由 QC 点击“放行”进入后续节点或“发货”终点。全部开单数量已经处理且没有待检、待返工数量后，系统自动结单。QC 录入返工后，对应批次显示“返工送检”，点击后仍在原工单下创建复检批次。装配节点后配置 QC 时也使用相同的送检、返工复检和自动结单交互。
