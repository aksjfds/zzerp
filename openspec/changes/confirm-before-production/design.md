# 设计

草稿只保存计划与产品明细。确认持有计划行锁并验证修订号，按产品ID顺序锁定产品，校验当前正式路线与数量，一次事务内替换无流水的旧安排、生成全部工单并写入确认信息；任一失败整体回滚。撤回仍要求无流水，并删除工单。已完成或曾确认后取消的历史保留；未确认草稿及从未确认的取消计划不进入生产查询。查询分页总数、数据和直接工单访问均使用确认信息及非草稿状态限制，防止旧版本遗留草稿记录泄漏；不连接或清理真实数据库。重建基线保留草稿明细，不预置工单。

物料交接保留原接收条件、组件引用与事件，位于部门工单卡片前方；两张卡片有独立边框、背景及间距。交接成功刷新工单；工单登记成功刷新交接，不增加第二个实例或重复请求。同步草稿提示文案与计划列表部门安排入口。

验证采用无缓存类型检查、Python/Vue/CSS静态解析与架构检查，不引入测试或数据库操作。本回退版本无可用 OpenSpec CLI，规范文件手工维护，严格验证和归档如实保留未完成项。
