# 设计

product_version新增value文本字段，去除首尾空白，长度1–100，同产品内唯一；version继续是内部递增数字标识，不改变已有外键类型。创建产品载荷新增必填version_value；新建外观版本接口接受version_value并校验，复制BOM/流程行为保留。版本选项响应由数字数组改为{version,value}数组，前端选择仍传内部标识，标签显示value。产品摘要和详情返回version_value，列表通过当前版本关联一次查询取值，避免逐产品懒加载。

新产品表单默认V1，可修改为任意文字或数字值；空白/超长拒绝。表单脏状态包含该值。已有版本的显示值本轮不提供改名接口。新版本通过输入弹窗填写并由同产品唯一约束处理并发冲突。提示及各表格直接显示保存值，保留用户要求的简洁文案。

计划明细与产品快照值契约新增source_version_value，复制时在产品锁内获取所选版本值，修改数量时保留该值。前端计划选项、列表、详情只读展示均使用保存值；快照不依赖工程当前名称。不新增持久化缓存、兼容回退、依赖或自动化测试。

SQL/ORM基线及种子同步，示例值V1。不会迁移或重建真实数据库；旧结构需先更新。本机缺运行依赖和OpenSpec CLI，运行验收、严格验证及归档不冒称通过；用无缓存类型、Ruff/复杂度、模板和静态架构检查核对。
