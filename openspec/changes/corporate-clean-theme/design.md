# 设计

依据：https://www.stylekit.top/api/design/corporate-clean/design.md?locale=zh

采用 corporate-clean 的 Implementation Contract：蓝色 #1e40af、画布 #f8fafc、白卡片、正文 #0f172a、次级文字 #64748b、边框 #e5e7eb；焦点使用 #3b82f6。字体 Inter 加系统及中文回退，不增加字体网络请求。卡片圆角12px、控件8px、徽标胶囊；轻阴影、8px间距基准。

复用 shared/theme 管理 DOM 与画布共同语义变量；组件样式修正 Element Plus 控件，页面 scoped 样式负责布局。登录采用浅蓝品牌栏和白色部门卡片；业务页统一白色标题区、内容卡片与清晰表头。普通入口最大1120px；数据表和工程编辑器按工作区铺满，避免压缩列、工具和流程图。表格在内部横滚，保留既有断点及手机操作规则。

仅微交互，时长最多200ms、ease-out；悬浮位移最多2px，只在精确指针上启用；按下缩放.98。焦点2px外环与2px间距；触摸目标至少44px；减少动效时禁用装饰位移。状态保留文字，徽标增加装饰圆点；保留已有错误、加载、空态与禁用条件。

不改变后端、鉴权、数据模型、请求、事件、数量计算、流程图节点位置/大小/锚点及路由；只调整节点颜色、圆角、描边与字体。通过无缓存类型检查、Vue/CSS解析和改动范围审查核对，不增加测试或运行构建/服务。

当前回退版本未包含 OpenSpec 命令或 pnpm spec 入口；手工维护标准变更结构，完成后同步规范并归档，明确记录未运行 CLI 验证。当前会话没有 StyleKit MCP 工具，已读取中文完整设计文档。

## 完整工作台重设计
用户明确要求超越换肤，范围扩展为真实页面结构与交互设计。应用组合根拥有 WorkspaceLayout；外壳读取现有鉴权和路由决定导航，shared 仅提供纯展示图标与标题。桌面使用白色固定侧栏、64px顶栏和浅灰工作区；手机侧栏变横向导航，不隐藏核心操作。账号与退出集中到外壳，移除页面重复退出入口。

产品与计划列表提供真实数据概览，分页数据明确标注“本页”，不通过浮点运算汇总业务数量。工程编辑器以章节导航组织基本资料、BOM和流程，锚点跳转保留所有草稿与组件实例。生产工作台以内联页签分开工单/进度和部门流水，按需挂载，保留请求取消与分页。表单以订单资料、产品明细、保存区分组。流程工作区使用节点库、画布上下文、属性面板、操作图例分区。登录页将管理入口与生产部门分组，保留已有登录方式和错误恢复。

保留路由守卫、未保存提示、所有权限条件、业务请求与校验；章节采用页面锚点，不以条件销毁编辑组件。业务页面不各自复制导航或持有全局登录状态。


退出导航需要与现有登录守卫配合：auth 的 endingSession 仅在退出动作期间置位，使登录页在此时允许进入；先执行路由离开守卫，取消时不调用退出接口或清除账号。导航成功后才结束会话，finally 恢复标志。退出失败用全局反馈显示，避免布局卸载后局部错误提示丢失。共享标题不再依赖账号或路由，未使用声明检查写入前端配置。
