# 设计

流水公共响应新增material_no，与material_name由同一实际物料节点确定：到料使用input_material_node_id，出料使用工单物料节点。普通配件取快照part_no，装配体按快照组成配件编号排序后以“ + ”连接，与工单编号规则一致。计算复用已加载的快照context，不新增数据库字段或查询；接口schema和前端值类型同步。部门流水仅将两字段合并到现有列，权限、分页、排序、数量及写入行为不变。

验证采用无缓存类型、Ruff/复杂度、模板与静态架构检查，不引入测试。后端运行环境缺FastAPI，应用运行及浏览器验收不冒称通过。OpenSpec CLI缺失，严格验证和归档暂不能执行。
